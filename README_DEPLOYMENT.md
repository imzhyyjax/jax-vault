### Web 版 vs iPhone App

## ❓ 常见问题速查

### Q1: 部署需要花钱吗？
**A**: 不需要！Vercel + Railway 免费额度足够个人使用。

### Q2: iPhone App 需要花钱吗？
**A**: 是的，需要 $99/年的 Apple Developer 账号。但 Web 版（PWA）不需要！

### Q3: 朋友怎么使用？
**A**: 直接发送网址，他们用浏览器打开即可。也可以"添加到主屏幕"。

### Q4: 数据安全吗？
**A**: 配置 API Key 后很安全。见 `QUICK_START.md` 的安全配置部分。

### Q5: 可以离线使用吗？
**A**: 基础版不行（需要联网）。高级 PWA 配置可以支持离线缓存。
